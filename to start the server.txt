Local development (from the project folder):

  cd backend
  python -m venv .venv
  .venv\Scripts\activate          (Windows)   |   source .venv/bin/activate   (macOS/Linux)
  pip install -r requirements.txt
  python app.py

Then open http://127.0.0.1:5000/ in your browser.

Full instructions, including Render deployment, are in README.md.
